# Student Performance Analysis

## Project Description

This project analyzes student performance using Python.

The project includes data cleaning and basic statistical analysis of student marks.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## Operations Performed

1. Load the dataset
2. Clean categorical data
3. Calculate Mean
4. Calculate Median
5. Calculate Mode
6. Calculate Standard Deviation
7. Calculate Quartiles
8. Analyze student scores

## How to Run

1. Open `studentsperformace.ipynb`
2. Open it in Jupyter Notebook or Google Colab
3. Run the cells one by one

## Objective

The main objective of this project is to understand student performance using data cleaning and statistical analysis.
