## WEEK 1
# SUPERSTORE SALES DATA ANALYSIS USING PYTHON

## DESCRIPTION

This task focuses on understanding and analyzing the Superstore Sales dataset using Python and Pandas.

## OBJECTIVES

* Load and inspect the dataset.
* Convert Order Date and Ship Date into datetime format.
* Calculate Delivery Days.
* Check categories and missing values.
* Calculate sales by category.
* Visualize sales using bar chart and histogram.

## WORKFLOW

**1. Load and Explore the Dataset**

* Load the CSV file using Pandas.
* Use `head()`, `info()`, and `describe()`.

**2. Data Processing**

* Convert date columns into datetime format.
* Calculate Delivery Days.
* Check missing values and categories.

**3. Data Analysis**

* Calculate total sales for each category.

**4. Visualization**

* Create a bar chart for sales by category.
* Create a histogram for sales distribution.
