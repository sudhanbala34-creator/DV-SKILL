## DESCRIPTION

This task focuses on understanding and analyzing the Superstore Sales dataset using Python and Pandas.

## OBJECTIVES

* Load and inspect the dataset.
* Convert Order Date and Ship Date into datetime format.
* Calculate Delivery Days.
* Check categories and missing values.
* Calculate sales by category.
* Visualize sales using bar chart and histogram.

* Calculate total sales for each category.
